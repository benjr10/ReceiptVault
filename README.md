ReceiptVault (Capstone Project)

Overview

ReceiptVault is a mobile app designed for small business owners and freelancers to quickly track and manage expenses.

The goal is simple:
Snap. Tag. Report. Done.

Users can capture receipts, categorize expenses, and generate reports — all within seconds.

---

Problem

Small business owners and freelancers struggle to:

- Keep track of physical receipts
- Organize expenses properly
- Prepare accurate reports for tax or accounting

Existing tools are often too complex or not designed for how these users actually work.

---

Solution

ReceiptVault provides:

- Fast expense logging (under 10 seconds)
- Receipt photo capture
- Automatic categorization
- Simple dashboards and reports

Everything is built for speed, simplicity, and clarity.

---

Core Features (MVP)

- Quick Expense Entry
- Receipt Photo Capture
- Category System
- Dashboard (spending insights)
- PDF Report Generation
- Authentication (login/signup)

---

Target Users

- Freelancers
- Sole traders
- Small business owners (1–5 people)

How We Work (IMPORTANT)

1. Do NOT work on the main branch

2. Create your own branch before starting

3. Name your branch based on your task
   
   - Example: structure-agent, john-agent-doc

4. Create your files inside the correct folder
   
   - Example: docs/agent.md

5. Commit your changes

6. Create a Pull Request (PR)

7. Wait for review and merge

---

Folder Guide

- docs/ → All documentation (.md files)
- design-system/ → Colors, typography (JSON)
- ui/ → UI implementation
- backend/ → Backend logic

---

Tech Stack

- Supabase → Database, Auth, Storage
- jsPDF → PDF report generation
- Vercel → Hosting
