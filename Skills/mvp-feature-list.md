# ReceiptVault – MVP Feature List

## 1. Overview
Defines feature scope for MVP.

## 2. Must Build
- Quick expense entry
- Category system
- Photo receipt capture
- Dashboard with spending view
- PDF report generation
- Authentication
- Offline mode
- Empty states and error handling

## 3. Should Build
- Project and client tagging
- Search and filters
- Recurring expenses
- CSV export
- Year-over-year comparison

## 4. Not in Scope
- AI receipt scanning
- Bank or card integration
- Multi-currency support
- Team accounts
- Custom report settings
