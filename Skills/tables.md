# ReceiptVault – Tables

## 1. Overview
Define how expense data is structured and displayed.

## 2. Data Structure

### Expense Record
- Date
- Amount
- Category
- Project (optional)
- Note (optional)
- Receipt Attached (Y/N)

## 3. Table Behavior

### Sorting
- Default: latest first

### Filtering
- Category
- Date range
- Amount range
- Project/client
- Combined filters supported

### Search
- Search by keyword in:
  - Notes
  - Descriptions

### Empty State
- Show message when no data is available
